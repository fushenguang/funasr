## 适用环境

| 资源 | 最低要求 | 推荐配置 |
|------|----------|----------|
| GPU | NVIDIA GPU + CUDA | RTX3060(12GB) 或更高 |
| 显存 | ≥8GB | ≥12GB |
| 内存 | ≥8GB | ≥16GB |
| 磁盘 | ≥20GB | ≥50GB |
| 系统 | Linux (Ubuntu 20.04+) | Ubuntu 22.04+ |
