## 前置条件

运行预检脚本确认环境就绪：

```bash
bash scripts/preflight.sh
```

检查项包括：Docker 版本、Docker Compose Plugin、NVIDIA GPU / Container Toolkit、系统内存 / 磁盘、端口冲突、网络连通性。

## 部署步骤

### 1. 配置环境变量

```bash
cp .env.example .env
# 按需编辑 .env
```

关键配置项：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `FUNASR_DEVICE` | `cuda` | GPU 推理设备 |
| `WS_ASR_MODEL` | `iic/SenseVoiceSmall` | WebSocket 离线 ASR 模型 |
| `WS_ASR_ONLINE_MODEL` | `iic/speech_paraformer-large_asr_nat-zh-cn-16k-common-vocab8404-online` | 流式 ASR 模型 |
| `WS_PUNC_MODEL` | `iic/punc_ct-transformer_zh-cn-common-vocab272727-pytorch` | 标点模型 |
| `FUNASR_API_KEY` | `funasr-internal` | API 鉴权密钥 |
| `NGINX_HTTP_PORT` | `80` | Nginx 对外端口 |

### 2. 预下载模型（推荐）

```bash
bash scripts/download_models.sh
```

首次启动时模型会自动从 ModelScope 下载（约数 GB），预下载避免启动超时。

### 3. 构建镜像

```bash
docker compose build
```

> 镜像基于 `pytorch/pytorch:2.4.0-cuda12.1-cudnn9-runtime`，安装 `funasr` + `vllm` + `fastapi` + `uvicorn`。

### 4. 启动服务

```bash
bash scripts/start.sh
```

脚本执行：
1. 构建镜像（若需要）
2. 启动所有容器
3. 等待健康检查通过
4. 打印服务状态

### 5. 验证部署

```bash
# 健康检查
curl http://localhost/health

# 语音转写测试
curl http://localhost/v1/audio/transcriptions \
  -F file=@sample.wav \
  -F model=sensevoice \
  -F response_format=verbose_json
```

## 服务管理

### 扩容

```bash
# 扩展 API 实例（Nginx 自动负载均衡）
docker compose up -d --scale funasr-api=3
```

### 停止

```bash
# 优雅停止（等待请求完成）
bash scripts/stop.sh

# 停止并清理
bash scripts/stop.sh --clean
```

### 日志查看

```bash
# 实时查看所有日志
bash scripts/logs.sh

# 只看 API 错误
bash scripts/logs.sh api --errors

# 请求统计（需要 jq）
bash scripts/logs.sh --stats
```

## 日志位置

| 日志 | 路径 | 格式 |
|------|------|------|
| Nginx 访问日志 | `logs/nginx/access.log` | JSON |
| API 服务日志 | `logs/api/funasr-api.log` | 结构化 JSON |
| WebSocket Runtime | `logs/runtime/` | 文本 |
| Docker 容器日志 | Docker json-file driver | 50MB 轮转 × 10 |

> 每条 API 日志记录：`request_id`、`filename`、`file_size_mb`、`model`、`audio_duration_s`、`inference_time_s`、`rtf`、`text_length`、`status_code`

## 网络拓扑

```
            ┌─────────────────────────┐
            │    Client (内网)         │
            │   HTTP / WebSocket       │
            └───────────┬─────────────┘
                        │ :80
            ┌───────────▼─────────────┐
            │    nginx (gateway)       │
            │    - /v1/*  → api       │
            │    - /ws    → ws        │
            │    - /health → api      │
            └──────┬──────────┬───────┘
                   │          │
          ┌────────▼──┐  ┌───▼──────────┐
          │ funasr-api │  │  funasr-ws   │
          │ ×N :8000   │  │  :10095      │
          │ least_conn │  │  ip_hash     │
          └────────────┘  └──────────────┘
                   │          │
          ┌────────▼──────────▼──────────┐
          │   models/ (ModelScope Hub)    │
          └──────────────────────────────┘
```
